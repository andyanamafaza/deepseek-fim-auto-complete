### You're ready to code

Open any source file and start typing - suggestions appear as ghost text.

| Key | Action |
| --- | --- |
| `Tab` | Accept |
| `Escape` | Dismiss |
| `Alt+]` / `Alt+[` | Next / previous suggestion |
| `Ctrl+Space` | Ask for alternatives |
| `Ctrl+Shift+.` | Toggle on/off |

Click the status bar item for quick actions, and tune everything under
**Settings → `deepseekFim`**.
